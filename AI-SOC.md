PROJECT: AI-Powered Cybersecurity Operations Platform

MISSION:
Build an educational, production-style AI-SOC platform for a final-year college project.

The platform should:
- ingest synthetic security logs
- detect suspicious events
- correlate events into incidents
- use AI/RAG to investigate incidents
- generate evidence-based incident reports
- show everything in a web dashboard

SAFETY RULES:
1. Use only synthetic logs and local test data.
2. Do not attack real systems.
3. Do not build malware, exploit automation, credential theft, or destructive tools.
4. AI may investigate and recommend, but must not take sensitive actions automatically.
5. All important actions must be logged.
6. Never hard-code secrets.
7. Every AI conclusion must include evidence.
8. Human approval is required for remediation actions.
9. Build this as a defensive security platform.
10. Every feature should have tests.
